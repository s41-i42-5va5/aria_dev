QUESTIONS AND ANSWERS

Before
you begin.

What is // A.R.I.A.?+

// A.R.I.A. is a local framework for managing and verifying digital product development with AI tools. It connects tasks, repository context, requirements, execution, review and evidence of the result.

How does // A.R.I.A. work with Codex and Claude Code?+

Codex and Claude Code have separate packages and integration skills. The Claude Code package also installs a protective PreToolUse hook. Codex or Claude Code must be installed and authenticated separately.

Where are the code and project state stored?+

The framework, product source code, // A.R.I.A. documents and local execution data have separate boundaries. The team workflow uses GitHub. AI data processing depends on the AI tool you use and its settings.

Do I need an always-on server?+

Local work does not require a central server. In the team workflow, the Coordinator runs on the owner's PC. While it is offline, confirmed GitHub events wait for synchronization; processing resumes when the Coordinator starts.

Does // A.R.I.A. guarantee error-free results?+

// A.R.I.A. verifies that defined conditions are met and preserves the evidence. The quality of the outcome depends on requirements, check coverage and the real environment. Framework verification does not replace acceptance testing of the product, external APIs or devices.
