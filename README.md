# // A.R.I.A. 1.5.5

Bilingual website for the A.R.I.A. engineering framework. Russian: `index.html`; English: `en.html`.

The site explains development with Codex and Claude Code: requirements, architecture, implementation, risk-based testing, independent review and evidence-based acceptance.

- 14 verification classes, Mission Supertest methodology and defect repair.
- Interactive risk plans calculated with the 1.5.5 engine.
- Source, documentation and Codex/Claude package downloads.

Static HTML, CSS and JavaScript. No build step or external libraries.

Website: https://s41-i42-5va5.github.io/aria_dev/

Framework: https://github.com/s41-i42-5va5/ARIA

Downloads: https://github.com/s41-i42-5va5/ARIA/releases/tag/v1.5.5

GitHub Pages publishes the root of main. Examples illustrate the process. The displayed risk plans are not reports of executed product tests.
