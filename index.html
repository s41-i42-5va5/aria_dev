01 / ПОДХОД

Больше кода.
Но что принято?

При работе с AI легко потерять связь между первоначальной задачей, изменениями и тем, что действительно проверено. // A.R.I.A. делает эту связь частью процесса.

ВОПРОСЫ И ОТВЕТЫ

До начала
работы.

Что такое // A.R.I.A.?+

// A.R.I.A. — локальный framework управления разработкой и проверкой цифровых продуктов через AI-инструменты. Он связывает задачи, контекст репозитория, требования, выполнение, review и доказательства результата.

Как // A.R.I.A. работает с Codex и Claude Code?+

Для Codex и Claude Code предусмотрены отдельные поставки и интеграционные skills. Поставка Claude Code также устанавливает защитный PreToolUse hook. Codex или Claude Code должны быть установлены и авторизованы отдельно.

Где находятся код и состояние проекта?+

Framework, исходный код продукта, документы // A.R.I.A. и локальные данные исполнения имеют отдельные границы. Командный контур использует GitHub. Обработка данных AI зависит от используемого AI-инструмента и его настроек.

Нужен ли постоянно работающий сервер?+

Для локальной работы обязательный центральный сервер не нужен. В командном контуре Coordinator работает на ПК владельца. Если он выключен, подтверждённые GitHub события ожидают синхронизации; после запуска Coordinator продолжает обработку.

Гарантирует ли // A.R.I.A. отсутствие ошибок?+

// A.R.I.A. проверяет выполнение заданных условий и сохраняет доказательства. Качество результата зависит от требований, покрытия проверок и реального окружения. Проверка framework не заменяет приёмку самого продукта, внешних API или устройств.
